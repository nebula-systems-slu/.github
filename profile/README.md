Aplicações web e infraestrutura AWS para empresas que dependem de tecnologia
que funciona. Você fala direto com o engenheiro — sem intermediários.

### O que fazemos

- **Web Engineering** — aplicações de alta performance em React, TypeScript e arquiteturas modernas
- **Cloud & Infraestrutura** — ambientes AWS desenhados para custo previsível e isolamento entre projetos
- **DevOps** — automação de build, deploy e observabilidade

### Como trabalhamos

Infraestrutura é código, não clique em console. Na prática, isso significa:

- Todo ambiente descrito em **Terraform**, versionado e revisado em pull request
- CI/CD autenticando por **OIDC** — sem chave de acesso guardada em lugar nenhum
- **Lint e scanner de segurança** bloqueando o merge, com exceções justificadas por escrito
- Cada cliente em **conta AWS isolada**, com custo e permissões separados desde o primeiro dia

`React` · `TypeScript` · `Node.js` · `AWS` · `Docker` · `Terraform`
